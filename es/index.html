Qué vas a crear

⚙️

Graphify

Lee un repositorio o una carpeta de documentos y extrae conceptos (nodos), conexiones (aristas) y comunidades — un mapa, no una búsqueda de texto.

🔮

Obsidian

Recibe el grafo en formato Markdown: un archivo por concepto, con backlinks automáticos y el documento fuente conectado a cada nodo.

🤖

Claude Code

Consulta este mapa dentro de tu vault — responde sobre repositorios grandes en el contexto de tu proyecto, no en un vacío aislado.

La ecuación del cheat code

↑ Las tres piezas se suman: el grafo de Graphify entra en el vault de Obsidian, y Claude Code empieza a recorrer ese mapa en vez de volver a leer todo desde cero.

Cómo funciona, en 4 pasos

Todo el flujo se dirige con lenguaje natural dentro de Claude Code. Describes el objetivo; este descarga, mapea y exporta.

1

Indica una fuente

Un código fuente o un corpus de documentos (PDF, docs, markdown). En el curso, descargamos la documentación oficial de Claude Code.

2

Ejecuta Graphify

Extrae conceptos y conexiones y genera el grafo (graph.html + graph.json).

3

Exporta a Obsidian

El modo Obsidian crea un archivo markdown por concepto con backlinks y vincula cada nodo al documento fuente.

4

Intégralo en tu vault

Vault aislado, subcarpeta de cuarentena, importación selectiva o redistribución: tú eliges cuánto entra en tu cerebro principal.
