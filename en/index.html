What you’ll build

⚙️

Graphify

Reads a repository or a folder of documents and extracts concepts (nodes), connections (edges) and communities — a map, not a text search.

🔮

Obsidian

Gets the graph as Markdown: one file per concept, with backlinks automatic and the source document connected to each node.

🤖

Claude Code

Query this map inside your vault — get answers about large repositories in context of your project, not in an isolated vacuum.

The cheat code equation

↑ The three pieces come together: Graphify’s graph goes into the Obsidian vault, and Claude Code starts navigating this map instead of rereading everything from scratch.

How it works, in 4 steps

The entire workflow is driven by natural language inside Claude Code. You describe the goal; it downloads, maps, and exports.

1

Point to a source

A source codebase or a document corpus (PDFs, docs, markdown). In the course, we download the official Claude Code documentation.

2

Run Graphify

It extracts concepts and connections and generates the graph (graph.html + graph.json).

3

Export to Obsidian

Obsidian mode creates one Markdown file per concept with backlinks and links each node to its source document.

4

Integrate into your vault

Isolated vault, quarantine subfolder, selective import, or redistribution — you choose how much goes into your main brain.
